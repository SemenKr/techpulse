# Current Sprint

## Goal

Build and stabilize the dashboard UI foundation before adding product complexity.

## Scope

* Dashboard UI foundation.
* Reusable dashboard components when they are clearly needed.
* Layout system.
* Visual consistency.
* Strict `src` architecture.

## Active Priorities

* Responsive dashboard layout.
* Sidebar and header consistency.
* Clean spacing and typography.
* Small readable components.
* Passing lint, typecheck, and build.

## Out Of Scope

* Auth.
* Backend complexity.
* WebSocket implementation.
* SSE implementation.
* Databases.
* Global state management.
* Mock APIs.
* Large feature modules.
* Overengineering.
