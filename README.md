# TechPulse

Real-time tech intelligence dashboard built with Next.js.

## Overview

TechPulse is a modern dashboard application focused on:

* real-time tech monitoring
* analytics and trends
* live activity feeds
* streaming updates
* interactive charts and filtering

The project is being built as a production-like frontend application to explore:

* modern React architecture
* realtime systems
* dashboard UX
* API orchestration
* scalable frontend patterns

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* shadcn/ui
* TanStack Query
* Zustand
* Recharts
* Framer Motion

## Features (Planned)

* Realtime dashboard
* Tech news aggregation
* GitHub trends monitoring
* Interactive analytics
* Live activity feeds
* Filtering and search
* Streaming updates
* Responsive dashboard UI

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run development server:

```bash
pnpm dev
```
